# Ecommerce competitor research by Storelens

Ecommerce competitor research as an agent skill: store spy reports, a theme detector and app detector, competitor product tracking, price tracking, best sellers and store leads. `SKILL.md` teaches an agent to research online stores with Storelens: which tool answers "what theme and apps does this store use", "what is my competitor launching", "what ads are they running" and "find Shopify stores to sell to", and which tools use the plan's allowance (monthly on Starter and Pro, one-time on Free).

Pair it with the MCP server at `https://storelensapp.com/mcp` (OAuth or an API key). Docs: https://storelensapp.com/developers/
